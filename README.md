# Propuesta Alorens Foods

Web: https://jarudigitalagency-hub.github.io/propuesta-alorens/

Versión estática de la propuesta Astro: 262 páginas, imágenes y catálogo PDF. Todas las páginas incluyen noindex, nofollow.

Este repositorio contiene la versión compilada lista para publicar, no los fuentes de Astro. El proyecto editable original sigue en el Mac.

GitHub Actions une los fragmentos de release/site.zip.part*, verifica SHA-256 y publica el contenido en GitHub Pages. El archivo está dividido para facilitar la transferencia. Para actualizar la propuesta, hay que regenerar la versión estática con la base /propuesta-alorens/, reemplazar los fragmentos y actualizar release/site.sha256.
